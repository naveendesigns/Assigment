# GCC Location Decision Brief

## Run locally

Install Node.js if it is not already installed, then open a terminal in this folder and run:

```powershell
npm start
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). Keep the terminal open while using the site; press Ctrl+C to stop the server. To use a different port, set the `PORT` environment variable before running `npm start`.

The server uses only Node.js built-in modules, so no package installation is needed.
